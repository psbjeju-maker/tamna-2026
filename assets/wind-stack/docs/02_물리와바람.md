# 물리·입력·바람 구현 규약

## 좌표와 크기
논리 화면 390×720. 물리 y는 아래 방향. 플랫폼 윗면 y=620, 폭=196, 높이=26, 중심 x=195. 배경과 캐릭터는 화면 좌표, 물건·플랫폼은 월드 좌표.
물건 10개로 탑이 화면을 넘을 수 있으므로 카메라가 위로 따라간다. 물리 월드·실패선은 이동하지 않는다. 실패선 y=735. HUD 숫자를 카메라와 함께 이동시키지 않는다.
크레인 좌우 범위 [54,336], 속도 95px/s부터. 다음 물건 준비 시 현재 안정 탑의 꼭대기보다 약 150px 위에 둔다. 이전 낙하 중 카메라/크레인 목표를 갑자기 바꾸지 않는다. 물건의 높이를 포함해 기존 탑과 겹치지 않는 시작 위치를 보장한다.

## 강체와 그림 매핑
`data/items.json`의 `sourceRect`는 원본 PNG에서 사용할 픽셀 영역이다. `renderSize`는 논리 px. PNG 전체를 renderSize에 억지로 늘리지 않는다. drawImage의 소스 영역에 sourceRect를 사용한다.
`collision.vertices`는 sourceRect 내부 정규화 좌표(0~1), `circle`은 정규화 중심과 반지름. 그림 기준점은 sourceRect 중앙이며 body의 무게중심과 다른 경우 centroid offset을 렌더에 적용한다. 물리엔진이 꼭짓점을 중심화하면 그림도 같은 offset으로 옮긴다.
이 팩의 충돌 윤곽은 **초기 수작업 근사치**다. 충돌선 디버그 오버레이로 각 물건을 실제 바닥에 놓고 검수해야 한다. 투명 이미지 파일의 사각형을 충돌체로 쓰지 않는다. 작은 귤 잎·돌의 이끼는 장식이며 충돌에서 제외한다.
구명환 중앙 구멍은 기본적으로 충돌하는 원형 몸체로 취급하는 단순화 초안이다. 내부로 다른 물건을 끼우는 플레이를 원하면 8~12개 볼록 파트의 복합체로 교체해야 한다. 선택 카드에 ‘둥근 몸체’로 표시하고, 구멍에 끼우는 기능을 광고하지 않는다.

## 시뮬레이션
엔진은 회전·마찰·다각형 충돌을 지원하는 2D 강체 엔진을 사용. 구현 전 선택한 엔진의 공식 문서/API를 확인한다. 이 팩은 특정 버전의 엔진을 번들하지 않는다.
고정 타임스텝 1/120s, 렌더는 requestAnimationFrame. 백그라운드 탭 복귀의 긴 delta를 한꺼번에 시뮬레이션하지 않는다. 충돌 누락 방지 서브스텝, 적절한 solver 반복횟수, 최대 낙하속도 조정.
질량은 상대 비율. friction/restitution은 엔진 단위로 변환한다. 착지 후 위치나 각도를 강제로 맞추지 않는다. 자동 수평 보정·자석·스냅 없음. 크레인에 잡힌 물건만 kinematic 또는 물리 밖에서 관리하고 놓을 때 동적 상태로 전환한다.

## 입력
pointerdown 한 종류만으로 낙하 처리. touchstart와 click을 중복 등록하지 않는다. Space는 keydown 반복(repeat)을 무시한다. HELD에서만 drop 가능. FALLING/SETTLING/RESULT에서는 무시. 버튼 클릭이 캔버스까지 전파돼 추가 낙하하지 않게 한다.
낙하 때 크레인 수평속도의 10%를 물건에 전달하는 초안. 지나가는 방향을 완전히 무시하거나, 수평으로 날아갈 정도로 전달하지 않는다. 상단에 방향이 보이게 한다.
첫 판은 바람 없는 3번의 낙하로 조작을 익힐 수 있다. 보이지 않는 실패 방지 보정은 사용하지 않는다.

## 안정화
현재 물건이 플랫폼/기존 탑에 접촉한 뒤, 연결된 탑 전체의 속도 < 6px/s 및 각속도 < 0.06rad/s가 0.65초 지속되면 안정. 접촉 그래프를 사용해 플랫폼과 연결된 물건을 찾는다. 화면 밖 낙하/실패는 안정화 검사보다 우선.
4초가 지나도 안정되지 않으면 ‘아직 흔들려요’ 짧은 표시. 6초 후 다음 물건을 잡을 수 있게 해도 기존 탑의 물리는 계속 계산한다. 마지막 물건에서는 6초 경과를 안정으로 간주하지 말고 12초까지 관찰 후 ‘불안정 종료’ 결과를 별도 표시한다. 무한 대기 방지이되 가짜 완주 판정 금지.

## 영등할망 바람 — 예고가 먼저
각 이벤트:
- 0.00~0.25초: 영등할망 화면 아래 측면 등장, 캐릭터는 게임 영역의 바깥쪽/가장자리.
- 0.25~1.25초: 미소, 말풍선, 방향 화살표와 강도 1~3칸. 이 1초 동안 힘 없음.
- 1.25~1.40초: 부는 표정으로 교체, 손 앞 바람 선 시작.
- 1.40~2.80초: 실제 힘 적용. 입/손 앞 시작점에서 해당 방향으로 흐르는 선. 파티클과 물리 힘의 방향 동일.
- 2.80~3.20초: 힘을 부드럽게 0으로, 미소로 복귀, 퇴장.

바람 세기와 캐릭터 표정만 보고도 도움/장난을 구분한다. 도움은 민트 + ‘살살 받쳐줄게’, 장난은 코랄 + 방향 화살표. 색상 외 문구/아이콘도 함께 제공한다.
장난: 옆바람. 가볍고 표면적 큰 물건이 더 영향을 받는다. 횡가속도 목표 18~55px/s², 물건 windResponse 곱. 강체 중심에 주된 힘을 가하고 작은 회전만 추가. 즉시 크게 튕겨내는 충격량 금지.
도움: 1.4초간 낙하 중 현재 물건의 유효 중력을 75%로 낮추고 각속도를 완만하게 감쇠. 미끄러지던 탑을 순간이동하거나 회전각 0으로 고정하지 않는다. 구제를 보장하지 않는다.
4/7/9번째 HELD 진입에 이벤트를 한 번 예약. 4는 약한 장난, 7은 도움, 9는 중간 장난을 기본값으로 사용. 매 판 물건은 다르게 골라도 바람 일정은 같아 비교 가능. 같은 슬롯에서 대기한다고 바람을 무한 반복하지 않는다.
3.2초 이벤트가 지나면 무풍이 된다. 사용자가 기다려서 피할 수 있는 것이 초기 버전의 허용 전략. 바람 중 안정 착지에만 +50점 보너스를 1회 주는 선택안은 별도 실험 후 적용(기본 점수에는 미포함). 낙하 제한시간을 넣는 경우 별도 테스트 후 예고 UI부터 추가한다.

## 착지·붕괴 피드백
가벼운 접촉: 아주 작은 먼지 4개, 재질별 짧은 톡 소리. 강한 접촉: 착지 충격파 1개, 먼지 8개, 약 60ms 표현상 눌림 후 원복. 물리 몸체 크기는 변형하지 않는다.
화면 흔들림 최대 2px/100ms, 큰 충돌에만. 물건 위치를 가리지 않는 높이 표시. 중복 접촉 이벤트 소리에는 물건별 120ms 쿨다운.
붕괴: 최초 실패 물건에 코랄 테두리 200ms → 실제 추락 → 0.8초 후 결과. 영등할망이 웃는 얼굴로 놀리는 듯 보일 수 있으므로 실패 결과 문구는 함께 아쉬워하고 재도전하는 톤.
효과음은 사용자가 첫 터치한 뒤 활성화. 음소거 가능. 진동 미지원이면 조용히 생략. reduced-motion에서는 큰 흔들림/번쩍임 제거, 물체 이동과 방향 예고는 유지.
