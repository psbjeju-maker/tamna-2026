# 바람탑 물건 20종 추가팩

기존 디자인과 어울리는 개별 투명 PNG 20개입니다. 각각 한 파일에 한 물건이 있어 시트 분할이 필요 없습니다. 원본 이미지는 그대로 보존했습니다.

## 새 물건
돌하르방 / 서핑보드 / 소라껍데기 / 불가사리 / 주전자 / 양동이 / 물뿌리개 / 장화 / 책 묶음 / 식빵 / 선인장 화분 / 필름 카메라 / 여행 가방 / 작은 북 / 닻 장식 / 나무 오리 / 쿠션 / 머그컵 / 나무 의자 / 소풍 바구니

## 30개로 사용하는 방법
기존 팩에는 12개가 있었습니다. 이번 20개를 모두 추가하면 총 32개입니다.
`data/catalog-30.json`은 기존 12개 + 신규 18개를 기본 후보 30개로 사용하며, 모양이 복잡한 신규 불가사리와 닻 장식을 예비 2개로 둡니다. 두 그림도 빠짐없이 포함했습니다. 예비 물건은 원하면 다른 물건과 교환할 수 있습니다.
**한 판에 고르는 물건은 여전히 10개**입니다. 30개는 후보 종류 수입니다.

## 파일
- `assets/items/*.png`: 새 물건 20개의 개별 투명 원본.
- `index.html`: 20종 그림과 파일명을 확인하는 로컬 카탈로그.
- `data/items.additional.json`: 기존 형식에 맞춘 추가 데이터. 표시 영역, 크기, 재질, 물리값 초안, 충돌체 근사치.
- `data/catalog-30.json`: 기본 30종 ID와 예비 2종 ID.
- `data/manifest.json`: 파일 이름, 원본 크기, 투명도, SHA-256.
- `merge-items.mjs`: 기존 items.json과 추가 데이터를 합쳐 별도의 새 JSON 생성.
- `CLAUDE_ADD_ITEMS.md`: 기존 게임에 추가하는 지침.
- `IMAGE_PROMPTS.md`: 이미지 제작 프롬프트 기록.

## 충돌체 주의
충돌체 초안은 알파 영역을 바탕으로 만든 단순 볼록 윤곽입니다. 손잡이 구멍·의자 다리 사이·주전자 주둥이 등 오목한 부분을 단일 볼록체로 쓰면 보이지 않는 판정이 생깁니다. 이런 물건은 데이터의 `requiresCompoundReview`를 확인해 여러 볼록 파트로 분해하고, 화면에서 그림 위에 충돌선을 겹쳐 검수해야 합니다. 제공한 물리값은 실기 테스트로 확정한 밸런스가 아닙니다.

이미지는 built-in 이미지 생성으로 제작했으며, 물건 PNG의 원본 픽셀을 후처리해 수정하지 않았습니다. sourceRect는 렌더링에 사용할 영역을 알려주는 메타데이터입니다.
