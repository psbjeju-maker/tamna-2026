# 디자인 규격과 파일 구조

## 방향
밝은 제주 바다, 따뜻한 크림색 패널, 짙은 청록색 글씨, 코랄색 장난 바람, 민트색 도움 바람. 물건은 손으로 집을 수 있을 듯한 질감과 명확한 외곽. 반짝이는 장식은 줄이고 물건 자체를 크게 보여준다. 영등할망은 기존 GOD4 이미지를 참조해 제작한 2개 표정으로 등장한다.

## 화면
| 화면 | 핵심 구성 | 행동 |
|---|---|---|
| 물건 선택 | 12개 카드, 선택 숫자, 선택한 10개 순서 목록 | 선택/해제, 앞뒤 순서 변경, 10개 확정 |
| 쌓기 | 높이/점수/남은 물건, 크레인, 탑, 바닥, 다음 물건, 짧은 바람 예고 | 한 번 탭해서 놓기 |
| 바람 개입 | 가장자리 영등할망, 미소/부는 표정, 방향과 종류, 바람선 | 흐름을 끊지 않고 판단 가능 |
| 결과 | 영등할망, 탑 최종 상태, 높이/쌓은 개수/점수 | 같은 조합 재도전, 선택 변경, 돌아가기 |

preview/index.html은 선택과 재정렬, 자동 왕복 크레인, 1회 낙하 연출, 두 종류 바람 연출, 결과 화면을 확인하는 시안이다. 예시 탑·예시 점수는 고정되어 있다. 실제 게임과 물리엔진을 구현한 파일이 아니다.

## 이미지 사용
- 물건 12개는 원래부터 한 파일에 한 개다. 자동 시트 분할이나 배경 제거를 다시 하지 않는다.
- 원본의 투명 여백/약한 주변광이 있을 수 있다. items.json의 sourceRect로 표시 영역을 맞춘다. 원본은 변경하지 않았다.
- PNG를 CSS 박스에 contain만 하면 물건마다 여백 때문에 표시 크기가 달라진다. 인게임에서는 sourceRect로 잘라 그린다.
- 충돌체는 sourceRect 전체 사각형이 아니다. items.json의 collision을 사용하고 디버그로 실제 윤곽을 검수한다.
- UI SVG는 코드로 작성된 벡터 자산이며 원하는 해상도로 렌더링할 수 있다. 물건 PNG와 별개다.
- 캐릭터는 왼쪽에서 오른쪽으로 부는 모습이 원본. 반대 방향에서는 캐릭터와 바람 이펙트 모두 좌우 반전. 글씨를 포함한 말풍선/UI까지 반전하지 않는다.
- 캐릭터 2장은 비율이 다르다. 같은 height만 주지 말고 얼굴 위치가 유지되게 각 sprite의 얼굴 기준점을 보정한다. 등장·퇴장 트윈만으로 전신 애니메이션을 만들었다고 주장하지 않는다.
- 배경은 중앙 물건 뒤 대비가 낮게 유지되도록 한다. 월드 카메라가 올라가도 배경을 확대/반복해 복잡한 암석이 탑 뒤로 올라오지 않게 하늘 그라디언트로 확장한다.

## 크레인 조립
레일 고정. trolley의 아래 중앙에서 케이블을 코드로 그린다. closed claw의 상단 중심 [40,0], open claw [52,0]를 동일 위치에 맞춘다. 두 이미지의 너비가 달라도 중심이 튀지 않게 한다. 케이블은 길이 조절이 필요하므로 별도 래스터 이미지가 없다. 물건 grip은 객체 로컬 정규화 좌표. 놓을 때 grip 구속만 해제하고 body 위치를 순간이동시키지 않는다.

## 크기와 가독성
모바일 기준 본문 16px, 짧은 라벨 13px, 점수 24px 이상, 터치 44px 이상. preview의 데스크톱 자산 카탈로그 캡션은 축약된 디자인 주석이다. 실제 모바일 선택 카드 설명은 더 크게 구현한다. 화면이 작으면 2열을 사용하고 세로 스크롤을 허용한다. 플레이 중 게임 영역은 touch-action:none, 나머지 선택 화면은 스크롤 가능.

## 오디오·효과
사운드 파일은 포함되지 않았다. 재질별 착지 소리 wood/stone/metal/ceramic/soft, crane_release, wind_warning, wind_blow, collapse, clear를 오디오 매니저 키로 준비한다. 실제 효과음은 사용 권한이 있는 파일을 넣거나 합성음을 구현한다. 이펙트 SVG와 코드 트윈을 사운드로 오인하지 않는다.
