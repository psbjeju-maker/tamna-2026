# 구현 후 검수 체크리스트

## 이 팩에서 확인한 것
- [x] 물건 12개와 캐릭터 2개가 각각 개별 RGBA PNG이고 투명 픽셀이 존재함.
- [x] 데이터의 이미지 경로가 실제 파일로 연결됨.
- [x] sourceRect가 이미지 영역 안에 있고 충돌점이 정규화 영역 안에 있음.
- [x] 상태 도우미의 10종 제한, 중복 선택 방지, 낙하 중 재입력 방지, 바람 슬롯 중복 방지, 종료 잠금 검증.
- [x] JavaScript 구문 검사.
- [ ] 실제 모바일 브라우저에서 미리보기 레이아웃/터치 확인.
- [ ] 강체 엔진 통합과 실제 게임 플레이. 이번 팩의 작업 범위에는 포함하지 않음.

## 개발자가 완료할 것
- [ ] 선택 9개/11개에서는 시작 불가, 같은 물건 2개 불가, 순서 변경이 실제 낙하 순서에 반영.
- [ ] 물건 그림과 충돌선이 맞음. 귤 잎 장식/구명환 내부 단순화는 규약대로 처리.
- [ ] 크레인 끝점에서 놓아도 자연스럽고, 놓은 물건을 자동 중앙 정렬하지 않음.
- [ ] pointerdown+click 중복, Space 길게 누르기로 2개 이상 떨어지지 않음.
- [ ] 30/60/120Hz에서 낙하·마찰·바람의 결과가 크게 달라지지 않음.
- [ ] 무거운 물건을 위에 두면 아래 탑이 실제로 움직이고, 착지 물건이 고정되지 않음.
- [ ] 바람 방향 예고와 실제 가속도/파티클 방향이 일치.
- [ ] 도움 바람도 실패한 물건을 되살리지 않음.
- [ ] 기울고 흔들려도 실제 낙하 전에는 게임오버로 오판하지 않음.
- [ ] 마지막 물건 투하 후 흔들리는 동안 성공 팝업이 뜨지 않음.
- [ ] 탑이 높아지면 카메라만 이동하며 실패선 좌표가 바뀌지 않음.
- [ ] pause/백그라운드에서는 물리와 바람 타임라인 모두 멈춤.
- [ ] 재시작 때 물리 월드·타이머·효과음이 중복 생성되지 않음.
- [ ] 결과 표시가 부모 앱의 보상 팝업에 의해 즉시 사라지지 않음.
- [ ] 소리/진동 없이도 착지, 위험, 바람 방향을 알 수 있음.
- [ ] 처음 보는 참가자가 크레인을 직접 드래그하려 하지 않고 ‘탭해서 놓기’를 이해.
- [ ] 무풍 상태에서도 한 번 더 놓고 싶음. 바람이 없으면 지루한 게임을 캐릭터만으로 덮지 않음.
- [ ] 실패한 참가자가 왜 무너졌는지 설명하고 다음 판에 물건/순서를 바꿔볼 수 있음.
