# 기존 바람탑에 새 물건 추가

새 게임을 만들지 말고 기존 ‘영등할망의 바람탑’ 후보 물건을 늘려주세요.

1. 이 폴더의 assets/items/*.png 20개를 기존 프로젝트의 assets/items/에 추가합니다. 기존 12개를 삭제하지 않습니다.
2. items.additional.json의 20개 레코드를 기존 items.json에 ID 기준으로 병합합니다. 원하면 함께 제공한 merge-items.mjs를 사용합니다.
3. 기본 후보는 catalog-30.json의 activeIds 30개만 표시합니다. reserveIds는 불가사리·닻 2개이며 교체용입니다. 한 판 선택 개수는 기존처럼 10개 유지합니다.
4. 그림은 sourceRect로 표시하고 renderSize의 종횡비를 유지합니다. 그림 전체 사각형을 충돌체로 쓰지 않습니다. 자동 중앙 정렬·착지 스냅은 추가하지 않습니다.
5. 새 물건의 collision은 자동 추출한 볼록 외곽 초안입니다. requiresCompoundReview=true인 물건은 오목한 부분/손잡이/의자 다리 사이에 빈 공간이 생기도록 복합 강체를 작성합니다. 특히 머그컵 손잡이와 나무 의자 두 다리를 단일 박스로 채우지 마세요. 나머지도 충돌선 디버그로 실제 접촉 위치를 확인합니다.
6. sourceRect 기준의 그림 중심과 엔진 강체 무게중심이 다르면 렌더 offset을 보정합니다. grip은 초기 제안이며 그림 상단의 안정적으로 집을 위치에 맞게 조정합니다.
7. 30종 카드에서는 모바일 2~3열과 스크롤을 사용합니다. 카드 설명 글씨를 줄여서 한 화면에 모두 우겨 넣지 않습니다. 현재 선택 개수/순서와 시작 버튼은 찾기 쉽게 유지합니다.
8. 현무암/돌하르방 같은 무거운 물건과 모자/쿠션 같은 가벼운 물건의 바람 반응을 구분합니다. 시뮬레이션 후 무게·마찰·표시 크기를 조정합니다.
9. 프리로드는 선택 화면용과 인게임 선택된 10개를 구분합니다. 원본은 고해상도이므로 필요하면 빌드 단계에서 작은 배포용 파생 PNG/WebP를 만들고 원본은 보관합니다.

완료 기준: 후보 30개, 중복 없이 10개 선택, 20개 신규 PNG 표시, 예비 2개 교체 가능, 떨어뜨린 물건 실제 윤곽과 충돌선 일치. 다른 UI·바람·보상 흐름은 이번 추가 작업 때문에 변경하지 않습니다.
