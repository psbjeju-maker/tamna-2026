# 영등할망의 바람탑 — 게임 설계 초안

## 사용자가 정한 핵심
여러 물건 가운데 10가지를 고른다. 크레인은 자동으로 좌우 이동하며 물건을 잡고 있다. 사용자가 클릭/탭하면 물건을 놓는다. 물건을 쌓는 도중 영등할망이 웃으며 나타나 바람으로 방해하거나 돕는다.

이 핵심을 바꾸지 않는다. 벽돌깨기, 공 반사, 전투, 보스, 스킬 진화는 넣지 않는다. 다음 수치와 상세 규칙은 시제품용 제안이며 재미 검증 후 조정한다.

## 한 판의 흐름
1. 12종 후보 중 서로 다른 10종 선택. 선택한 순서가 투입 순서. 위/아래 버튼으로 재정렬.
2. ‘내 탑 쌓기’로 시작. 첫 물건을 크레인이 잡고 자동 왕복. 사용자는 이동시키지 않고 놓을 순간만 고름.
3. 탭/클릭 또는 Space로 1개 낙하. 누르고 있는 동안 반복 낙하하지 않음.
4. 착지 후 흔들림을 확인. 안정되면 다음 물건이 크레인에 등장.
5. 4·7·9번째 물건을 잡기 시작할 때 바람 이벤트 예약. 영등할망 등장 → 미소 → 방향/종류 예고 → 바람 불기 → 물건 반응 → 퇴장.
6. 물건이 받침에서 떨어져 실패선 아래로 내려가면 이번 판 종료. 보이지 않는 보호막·자동 복구 없음.
7. 10개를 모두 떨어뜨리고 안정화되면 완주. 영등할망 축하, 최종 높이·점수·최고 기록 표시. 본인이 재도전/선택변경/돌아가기를 선택.

## 재미의 중심
- 준비: 잘 받쳐주는 물건을 아래에 둘지, 높은 물건으로 기록을 노릴지.
- 조작: 왕복 크레인의 위치와 바람을 읽고 놓는 한 번의 선택.
- 관전: 휘청거리다 멈추는 탑. ‘버텨라!’ 하는 순간을 잘 보여주기.
- 재도전: 실패한 위치와 물건 순서를 기억하고 다음 판에 바꾸기.

선택 화면에 무게 수치 대신 ‘넓고 든든’, ‘잘 구름’, ‘가볍고 바람에 약함’처럼 결과를 예상할 짧은 설명을 보여준다. 점수 효율이 좋아도 쌓기 어려운 물건을 섞는다. 안정형만 고르는 문제가 생기지 않는지 테스트한다.

## 영등할망과의 관계
이 게임은 ‘영등할망이 참가자와 바람 쌓기 놀이를 한다’는 창작 상황이다. 웃음·바람·탑의 흔들림이 하나의 행동으로 이어져야 한다. 신화의 의례를 재현했다고 설명하지 않는다.

시작: “열 가지 골라 보렴. 어디까지 쌓나 볼까?”
장난 예고: “후후, 이번엔 이쪽으로 불어 볼까?”
도움 예고: “살살… 이번엔 내가 받쳐 주마.”
위태로운 착지: “어어, 버틴다!”
완주: “열 개를 다 올렸구나! 제법인데?”
실패: “아이고, 와르르! 이번엔 순서를 바꿔 볼까?”

표준 한국어 임시 대사다. 제주어 감수는 별도. 짧은 말풍선만 쓰며 전체 화면 대사창으로 플레이를 끊지 않는다.

## 실패와 종료
- 바닥 받침만 고정체. 물건은 착지해도 동적 강체로 유지한다.
- 화면 아래 실패선에 물건 몸체 전체가 내려가거나, 옆으로 화면을 완전히 벗어난 상태가 0.3초 지속되면 실패.
- 흔들리거나 기울어졌다는 이유만으로 실패시키지 않는다. 실제 낙하를 보여준다.
- 이미 쌓인 물건이 떨어져도 실패. 낙하 중인 현재 물건과 기존 물건 모두 검사한다.
- 실패 확정 후 다음 물건 생성/점수 추가/바람 예약을 중지한다. 약 0.8초 붕괴를 보여주고 결과 표시.
- 마지막 물건은 최종 안정화가 끝나기 전 완주 처리하지 않는다.
- 도움 바람은 중력·각속도를 제한적으로 줄이는 효과. 실패선을 넘은 물건을 되살리지 않는다.

## 점수 초안
안정적으로 받침과 연결된 물건마다 최초 1회 100점. 해당 물건 난이도 점수(0/40/80)를 1회 추가. 안정된 연결 탑의 높이 1px당 2점(논리 화면 기준), 완주 500점.
낙하 중 순간적으로 높았던 물건, 크레인에 잡힌 물건, 붕괴 중 날아간 물건으로 높이를 갱신하지 않는다. 결과 높이는 마지막으로 확정된 안정 상태. 실패 전 확정 점수는 유지한다.
같은 조건의 비교를 위해 기본 순위에는 10개 구성과 순서·룰 버전·바람 시드도 기록한다. 공식 행사 순위는 고정 일일 시드/동일 후보로 운영하는 것을 권장한다. 실제 공유 순위 서버는 이 팩에 포함되지 않는다.

## 재미 검증 순서
먼저 무풍 상태에서 상자·판자·귤 3종으로 ‘조작-낙하-착지-붕괴’가 재미있는지 확인한다. 다음 전체 물건을 연결하고, 마지막에 바람을 넣는다. 모델/캐릭터 그림을 넣었다는 이유로 재미가 완성됐다고 판단하지 않는다.
