# 영등할망의 바람탑 — 디자인·개발 시작팩

물건을 10개 고르고, 좌우로 움직이는 크레인에서 탭해 떨어뜨려 쌓습니다. 영등할망은 웃으며 바람으로 장난치거나 도와줍니다.

## 먼저 보기
`preview/index.html`을 브라우저에서 열면 물건 선택/순서 변경, 크레인과 낙하 연출, 영등할망의 바람 연출, 결과 디자인을 확인할 수 있습니다. 로컬 파일 실행이 제한되는 환경에서는 이 폴더에서 `python3 -m http.server 8000`을 실행한 뒤 브라우저로 `http://localhost:8000/preview/`에 접속하세요.

## Claude에 전달
ZIP 전체를 풀고 `CLAUDE_START.md`를 먼저 읽게 하세요. 개별 PNG가 이미 있으므로 시트 자르기나 새 누끼 작업은 필요하지 않습니다. `data/items.json`을 따라 표시 크기와 충돌체를 연결하세요.

## 포함
- 물건 12개 투명 PNG: 귤 상자, 현무암, 판자, 귤, 부표, 차 통, 조개, 옹기, 나무 물고기, 밀짚모자, 선물 상자, 구명환.
- 영등할망 투명 PNG 2개: 웃음, 바람 불기. 기존 사용자 캐릭터 참조.
- 제주 해안 배경 1개.
- 크레인 부품, 플랫폼, 바람/착지 효과, 아이콘 SVG 14개.
- 디자인 미리보기, 게임 설계/물리/바람/파일 구조/검수 MD, JSON 데이터, JS 시작 코드와 상태 테스트.

## 범위
**완성 게임이 아니라 디자인과 구현 시작팩입니다.** 미리보기의 낙하는 연출용 고정 위치 이동이고 실제 물리 쌓기가 아닙니다. 점수·높이는 디자인 예시입니다. 충돌 윤곽과 물리 수치는 초기 근사치이며 엔진 통합 후 조정해야 합니다. 효과음 파일과 공용 순위 서버는 포함되지 않았습니다. 모바일 실기 검증은 아직 하지 않았습니다.

이미지는 built-in 이미지 생성으로 제작했습니다. 프롬프트와 원본 참조는 docs/IMAGE_PROMPTS.md, 에셋 경로/검증 해시는 manifest.json에 있습니다. 이 게임과 영등할망의 대화는 창작 놀이 설정이며 실제 의례 재현이 아닙니다.
